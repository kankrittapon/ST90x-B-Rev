## บทเรียน API (KiCad 10 / python)

- `PCB_FIELD.GetShownText()` ต้องใส่อาร์กิวเมนต์ `aAllowExtraText`
- `track.GetClass()` ของ via คืนค่า **"PCB_VIA"** (ไม่ใช่ "VIA") — ใช้ `isinstance(t, pcbnew.PCB_VIA)` ปลอดภัยกว่า
- `shape.GetLayerName()` ใน KiCad 10 คืน "F.Silkscreen" ไม่ใช่ "F.SilkS" — เทียบ layer id แทน
- text bbox ของ DRC (half-height) ≈ size/2 + thickness/2 พอดี; `GetBoundingBox()` ของ text บวก pad เพิ่ม (~0.28/ด้าน) — ใช้ค่า DRC เป็นหลัก
- แก้ poly ด้วย `SetPolyPoints(VECTOR2I abs)` แล้วอ่านกลับมาตรวจได้ตรงตามที่ตั้ง
