## ภาพรวมก่อนหน้านี้

GND fill ในบอร์ดมี **4 ชิ้น** (นับรวม 2 เลเยอร์) และเดิมมี via GND **ตัวเดียวทั้งบอร์ด** = (29.50, 45.00) — สะพานเดียวระหว่าง F main ↔ B main จึงแยกเป็น 2 กลุ่มไฟฟ้า: {F main ↔ B main} กับ {เกาะ F, เกาะ B} ที่ติดกับ pad เดียวเท่านั้น
- ⚠ เม็ดมิล (11.50, 44.00) ที่อยู่ใกล้จุดกลางนั้นเป็นเน็ต **GPS_RF** (ทางอาหารเสาอากาศ GPS) — **ไม่ใช่ GND**
- บอร์ดนี้ **ไม่มี pad แบบ through-hole เลย** (225 pads = SMD ทั้งหมด) — การต่อ F↔B จึงทำได้ทาง via เท่านั้น

## สาเหตุของเกาะแต่ละชิ้น

### เกาะ F (NE block) — ถูกปิดด้วยแถบ anti ต่อกันเป็นรอยเดียว
- กำแพงตะวันตก: anti ของ LED_4G/CHR (x 25.075..25.725) **แตะ** anti ของ LED_EN (x 25.725..26.375) **พอดี x = 25.725** → แผ่นตะวันตกถูกผนึกสนิท
- ตัดใน: BOOT F v x=27.00 (anti ลึกเข้าไปในบล็อก)
- ช่องว่างไม่มี fill อื่นเปิดทางออก (J7 pads + ขอบสนามรัศมีรอบ pad)
- แถบ east strip x 34.03..34.50 (y 32..73.4) ติดกับบล็อก NE เป็นชิ้นเดียวกัน (poly เดียว)
- **ยังไม่ทราบสาเหตุชัดเจน**: แถบว่าง x ≈32.6..34.03 × y 32..73 (ไม่มี fill) — ไม่กระทบการซ่อม ปล่อยไว้

### เกาะ B (south band) — ถูกกรงด้วยเส้น PKEY ของตัวเอง + กำแพง power
ทางออกเดียวของแถบล่างถูกอุดทั้งหมด:
- PKEY B v x=1.625 อุดช่อง x 1.35..2.025 (เว้น 0.20 พอดีสองฝั่ง)
- PKEY v x=10.15 / h y=66.30 / v x=4.00 / h y=70.40 กั้นตามหลัก
- anti ของ via VBAT (1.00,44.15) + เส้น VBAT h y=69.50, y=72.80
- กำแพง via M3V3 (5.50/7.50/9.50, 62.00) + via G3V3 (1.75,60.80) กับ (5.60,60.80)
- ผลลัพธ์: เกาะ B มี **via GND = 0** และ pad TP6.1 เป็น SMD ฝั่ง B เท่านั้น → กระเป๋าไฟฟ้าแยก

| ทางแก้ | ตำแหน่ง | เชื่อมอะไร | ระยะ clearance |

| GND stitching via 2 | (30.00, 15.00) | เกาะ F ↔ B main | 0.6/0.3 — เลือกจุดพ้น U5 (y ≥ ~31) และ pads J7 (y ≈25.5) |

ผลลัพธ์: **ทั้ง 4 ชิ้นต่อกันหมด** ผ่านกราฟ 3 เส้น
```

F main ── stitch (2.50,71.20) ── เกาะ B
B main ── stitch (30.00,15.00) ── เกาะ F
```
- ก่อนซ่อม: DRC `unconnected_items` = 2 คู่ (เกาะ F ↔ F main, เกาะ B ↔ F main — เรตเนสต์ผ่าน zone)
- หลังซ่อม: **unconnected = 0** (DRC รอบสุดท้าย 45 warnings / 0 errors / 0 unconnected)

## วิธี probe (ทำซ้ำได้)

`scripts/p3_probe.py` (รันด้วย pcbnew standalone):
1. `LoadBoard` → เก็บ zone `/GND` ทุกตัว → `GetFilledPolysList(F_Cu / B_Cu)`
2. ray-casting point-in-polygon บน outline จริง (คำนวณจาก vertex ระดับ µm แปลงเป็น มม.)
3. พิมพ์: แต่ละจุดทดสอบอยู่ใน poly หมายเลขใด (`-` = ไม่มี fill) + ตาราง pad GND ทุกตัว (อยู่ใน poly ไหน, เป็น SMD ฝั่งไหน)

⚠ อย่า refill แล้วบันทึกทับจาก KiCad GUI ที่เปิดอยู่ — จะย้อน fill/tracks กลับเป็นสถานะเก่า
